# EssayForge AI

## What this is

EssayForge AI is a local-first AI college admissions essay coach.

It helps students:
- discover personal stories
- brainstorm essay ideas
- improve drafts
- analyze essays
- preserve their authentic writing voice

It is NOT an AI essay generator.
It is an AI essay coach.

## Current Stack

Frontend:
- Next.js 15 App Router
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- Framer Motion

Backend:
- Next.js API routes/server actions
- SQLite
- Drizzle ORM

Editor:
- Tiptap

AI:
- LM Studio local server
- OpenAI-compatible API

Default AI endpoint:
http://localhost:1234/v1

No cloud AI APIs.
No mock AI responses.
